# Rendering & Landscape Design Cost Data (US)

> Open, source-attributed pricing data for **3D architectural rendering** and **landscape design** in
> the United States. Brand-attributed prices are **real published prices**; industry figures are
> clearly labelled as ranges. Free to use (CC0). Maintained by [Ratio Visuals](https://ratiovisuals.com).

_Last updated: 2026-09-12. Prices are reviewed regularly against the source pages below._


**Quick answer:** In the US, a single 3D architectural rendering typically runs **$300–$1,500** for a
still image, while professional **landscape design** starts around **$200 for a 2D plan** and
**$400–$720 for a photorealistic 3D design**, depending on yard size. Full-yard 3D design (front +
back) is **$1,296**. Costs scale with detail, number of views, and whether you need animation.

## What drives the cost

| Factor | Effect on price |
| --- | --- |
| Detail & realism level | Photoreal materials, lighting and post-production cost more than draft/clay renders. |
| Number of views / angles | Each additional camera angle is priced separately in most studios. |
| Still image vs animation | Animation (video walkthroughs) costs many times more than a still due to per-frame rendering. |
| Scene complexity | Large sites, dense planting, water features and crowds add modeling and render time. |
| Source material quality | Clean CAD/BIM or measured drawings reduce cost; vague sketches add modeling time. |
| Turnaround speed | Rush jobs carry a premium; standard turnaround is typically 5-10 days. |
| Revisions included | More included revision rounds raise the base price. |
